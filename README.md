# Clarte_HR_ANalysis

This repository contains the source code, data pipelines, and visualization configurations for the Clarte HR Dashboard.
The platform aggregates complex employee data into actionable insights, helping HR professionals and executive leadership 
make informed, data-driven decisions about workforce planning and talent optimization.

✨ Key Features
•	Global Workforce Tracking: Real-time monitoring of Clarte's global strength (currently tracking 797 active employees).
•	Role-Based Performance Analysis: Comparative metrics contrasting managerial versus non-managerial output and salary 
distributions.
•	Regional Performance Banding: Geospatial breakdowns highlighting top-performing sectors, with deep-dives into the West, 
Midwest, and Northeast regions.
•	Demographic Mapping: Cross-departmental analysis of age distributions and operational baselines across core divisions 
(Sales, Marketing, HR, Finance, Operations, Customer Support, and Leadership).

📊  Dashboard Insights
•	The Manager Gap: Data reveals that individual contributors account for a significantly higher volume of peak performance
markers (674) relative to their population size compared to managerial tiers (161).
•	Regional Drivers: The West region consistently outpaces other domestic zones in both salary structures and high-performance
metrics.
